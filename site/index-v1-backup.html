Questions, answered.

Is Isolate Client free?
Yes. The launcher, profiles, mods, hosting and partnerships are free. Solute ranks are optional paid tiers that add extras like voice chat.
Is it safe?
Isolate uses real Microsoft login for premium accounts. No game files are modified beyond what you install yourself.
What does 700 FPS actually mean?
It is the number we target and routinely hit in vanilla scenes with the default performance profile. Your frames depend on hardware; the launcher gives you the settings to get there.
