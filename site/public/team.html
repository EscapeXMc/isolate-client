The story behind Isolate Client

Why we built it

We both play Minecraft a lot, and the same problem kept ruining the fun: lag. Frame drops in fights, long loading screens, and launchers that ship more bloat than the game itself. Popular clients were heavy, complicated, or locked behind paywalls — and on a normal PC, none of them felt "light" anymore.

So we asked a simple question: what if a Minecraft client did only what matters — run fast, install mods in one click, and stay out of your way? No ads, no bloat, no nonsense. That question became Isolate Client.

How it started

It began as a personal project between the two of us — a way to fix our own FPS problems instead of waiting for someone else to. We sketched the launcher, argued over every feature, and kept one rule the whole way: if it doesn't make the game faster or easier to play, it doesn't ship.

What started as a private build for ourselves grew into a full launcher with a website, a companion mod, one-click mod installs, profile switching, and a free-for-everyone release. On 18 November 2026, Isolate Client launched publicly.

How we built it

The launcher is written in Rust with Tauri, so it stays tiny, starts fast, and doesn't eat your RAM while Minecraft uses it. Under the hood there's a Fabric companion mod — IsolateClientMod — plus a carefully tested set of ~58 performance mods that ship ready to play.

Everything is verified end-to-end: install flows, auto-updates, mod injection, and the website you're reading now. The whole stack — launcher, mod, site — is built and tested the same way we'd want it if we were the ones downloading it.
